Membina Sistem Pengkalan Data Murid Menggunakan Apps Script

Langkah demi langkah cara saya memanfaatkan Google Sheets dan HTML untuk memudahkan semakan maklumat murid di makmal komputer.

Bagi menguruskan data penggunaan makmal komputer, proses manual sering kali memakan masa. Oleh itu, saya telah membangunkan satu sistem web aplikasi ringkas yang membolehkan proses carian nama murid dibuat terus melalui pelayar web.

Mengapa Google Apps Script?

Google Apps Script adalah percuma dan bersambung terus dengan Google Sheets. Ini bermakna, guru-guru lain juga boleh menambah atau menyunting data murid di dalam jadual (spreadsheet) tanpa perlu mengetahui apa-apa tentang kod pengaturcaraan.

  • Tiada kos server bulanan.
  • Mudah dikemas kini (hanya buka fail Sheets).
  • Boleh diakses menggunakan telefon bimbit.

Langkah-langkah Persediaan

Pertama, sediakan satu fail Google Sheets. Dalam sheet ini, pastikan tab data anda dinamakan dengan betul (saya menggunakan nama tab DATABASE BARU untuk menyimpan rekod murid).

Nota: Pastikan nama tab dalam Sheets sepadan dengan nama yang diletakkan dalam kod Apps Script anda.

Selepas itu, buka menu Extensions > Apps Script dan masukkan kod HTML serta fungsi carian yang diperlukan.
